# LEARN-N.md

## Запуск проекта

```bash
npm run dev
```

Запускает dev-сервер Vite (`http://localhost:5173`).

## Сборка

```bash
npm run build
```

## Линтеры и форматирование

```bash
npm run lint            # TypeScript + ESLint проверка
npm run lint:fix        # Автоисправление проблем от ESLint
npm run format          # Форматирование кода через Prettier (с записью)
npm run format:check    # Проверка форматирования без записи
```
